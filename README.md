# FlowDesk

FlowDesk is a multilingual one-page website created as a frontend course project.

## Languages

- English
- Arabic
- German

## Features

- Responsive design
- Language switching
- RTL support for Arabic
- Interactive workflow demo
- FAQ section
- Contact section

## Technologies

- HTML
- CSS
- JavaScript

## About

FlowDesk is a fictional business automation service created for learning and demonstration purposes.
